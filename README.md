This repository contains the code and data used for the paper titled "Stochastic Gradient Methods for Sensitivity Analysis and Optimization in Epidemic Models under Parameter Uncertainty," submitted to IISE Transactions.

Explanation of the directory structure:
- `output`: Contains simulation output data and figures used in the paper.
- `scripts`: Contains the Python scripts used to run simulations and analyze the data. See docstrings/comments for descriptions of the purpose of a particular script.
- `snippets`: One-off scripts written to test functionality of the code.

The simulation model is implemented in `tsir_wd.py`.

Filepaths in scripts are written relative to the root directory of this project, i.e., set your IPython shell's working directory to the root.
